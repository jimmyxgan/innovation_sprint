# Short isometric reactor sensor visualization

The HMI now uses a translucent hollow cylinder with a reduced height-to-diameter ratio (~0.64), five axial contact-AE rings on each of the inner and outer winding surfaces (8 circular nodes per ring), and separate top/bottom rim microphone rings (8 square nodes per ring). Total: 80 AE + 16 microphone channels.

Drag horizontally to rotate. Excited sensors illuminate based on the synthetic event response. Sensor installation, transfer functions, localization, and physical mounting approval are not validated.

Run: `pip install -r requirements.txt` then `python app.py --demo --reset-demo-db`.
